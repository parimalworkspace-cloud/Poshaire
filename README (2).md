# Poshaire

**Your Story. Our Threads. Wear Your Story.**

Live customiser for unisex streetwear, cotton sarees and Mens Regal (modi jackets, shirts, kurtas).
Pick a piece, colour it, add art, words or your own image, and preview it on a model, front and back.

Single-file site: everything (code, images, models) is inside `index.html`. No build step.

## Run locally
Open `index.html` in any browser.

## Host free on GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
